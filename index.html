How to Insert Data into TIDE

Telemetry pipeline for NARA buoys, SL Navy Hydrographic stations, and Ocean University (OCU) coastal nodes.

Method 1: Direct CSV / In-Situ Data Upload

Upload daily or hourly coastal readings containing the 6 required oceanographic parameters.

Click to select or drag & drop a CSV dataset file
Supported columns: timestamp, sst, do, salinity, turbidity, ph, chl_a
Method 2: Codebase Configuration File (js/site_data.js)

You can add new stations directly into the SITE_DATABASE object inside js/site_data.js with baseline values, coordinates, and data provider attribution: 

SITE_DATABASE["mirissa_bay"] = {
  name: "Mirissa Fishery & Whale Sanctuary",
  dataProvider: "sl_navy", // "nara" | "sl_navy" | "ocean_univ"
  sensorNode: "SL-NAVY-SOUTH-MIR01",
  baseValues: { sst: 29.1, do: 4.8, salinity: 33.5, turbidity: 9.0, ph: 8.0, chl_a: 3.2 }
};
Method 3: Live REST API / IoT Buoy Stream (Backend Integration)

For automated continuous feeds, connect your Python/FastAPI backend to fetch real-time buoy streams and push JSON telemetry directly into the frontend via WebSocket or fetch('/api/v1/telemetry?station=NARA-01').

Marine Ecosystem Stress Index (MESI) Formulation

NARA-calibrated composite index (0–100) from 6 physical/chemical parameters:

MESI = 0.25·S_SST + 0.25·S_DO + 0.15·S_Salinity + 0.15·S_Turbidity + 0.10·S_pH + 0.10·S_Chl-a
  • SST [25%]: Baseline 28.0°C. Exponential stress above 29.5°C.
  • Dissolved Oxygen [25%]: Baseline 6.5 mg/L. Hypoxia onset below 3.5 mg/L (Critical <2.0 mg/L).
  • Salinity [15%]: Baseline 34.0 PSU. Freshwater dilution stress below 25.0 PSU.
  • Turbidity [15%]: Baseline 5.0 NTU. Particulate stress spikes above 15 NTU.
  • pH [10%]: Optimal 7.8–8.2. Deviation = acidification or alkalinity stress.
  • Chlorophyll-a [10%]: Baseline 2.0 µg/L. Bloom potential above 10 µg/L.
Categories: 0–30 Low/Stable  |  31–55 Moderate Stress  |  56–75 High Stress  |  76–100 Critical Hazard
